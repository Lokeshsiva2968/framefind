
# FrameFind

FrameFind is an image-search app designed to help people discover visual inspiration from topics they care about. I chose a forest-green and ivory colour palette to create a calm, editorial feel that stands apart from typical image-search interfaces. I added quick-explore chips so users can immediately see examples of topics they could search for. The responsive CSS Grid and empty-state message prepare the gallery for image results in Part 2 while keeping the first visit clear and welcoming.
